# Informe de Laboratorio

Este repositorio contiene los archivos, evidencias y documentación correspondientes al **Informe de Laboratorio Evaluativo**. Su propósito es registrar de manera organizada el desarrollo de la práctica, los procedimientos realizados y los resultados obtenidos.

## Objetivo

El objetivo de este laboratorio es aplicar los conceptos estudiados durante la asignatura mediante una actividad práctica, documentando el procedimiento realizado y presentando las evidencias necesarias para demostrar su correcta ejecución.

## Estructura del repositorio

El repositorio se encuentra organizado en las siguientes carpetas:

* **`laboratorios/`**: contiene documentos adicionales, explicaciones y material relacionado con el desarrollo del laboratorio.
* **`ejercicios-clase/`**: contiene todos los trabajos que se realicen durante el semestre.
* **`benchmarks/`**: almacena las prueba de rendimiento o análisis comparativos que miden y evalúan la capacidad de un sistema frente a otros estándares.
* **`README.md`**: contiene información general del curso y la plantilla para presentar informes.
* **`.gitignore`**: contiene los archivos que se deben de ignorar para no subirlos a github.

## Procedimiento

Para desarrollar el laboratorio se realizaron los siguientes pasos:

1. Análisis de los requerimientos de la práctica.
2. Preparación del entorno de trabajo.
3. Ejecución de los procedimientos solicitados.
4. Registro de evidencias.
5. Validación de los resultados obtenidos.
6. Documentación del proceso realizado.

A continuación se presenta un ejemplo de los comandos utilizados durante el desarrollo del laboratorio:


**Nota:** Los comandos anteriores deben reemplazarse o complementarse con los comandos utilizados específicamente en cada laboratorio.

## Resultados

Durante el desarrollo del laboratorio se ejecutaron correctamente los procedimientos planteados y se recopilaron las evidencias correspondientes. Los resultados obtenidos pueden consultarse en las carpetas **`evidencias/`** y **`resultados/`** del repositorio.

## Conclusiones

El desarrollo de este laboratorio permitió aplicar de manera práctica los conceptos estudiados, comprender mejor el funcionamiento de las herramientas utilizadas y fortalecer las habilidades relacionadas con la ejecución, análisis y documentación de procedimientos técnicos.
